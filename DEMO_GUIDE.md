# Jury Demo Guide

Start on Home and point out the distinction between model perspectives and evidence-backed verification.

1. Run **Conflicting Answers**. Show differing model cards, the rejected Redis claim, trusted evidence, conflict handling, and limited final conclusion.
2. Run **Self-Correction**. Show the erroneous initial arithmetic claim, correction timeline, deterministic re-check, and final certificate.
3. Run **Hallucination Test**. Show that a fictional Nimbus API claim remains rejected despite some model perspectives asserting it.
4. Run **Ambiguous Question** or **Insufficient Evidence**. Show a clear refusal to invent certainty.
5. Open Model Lab, Analytics, Settings, and the Markdown/JSON exports to demonstrate routing, evaluation, secret safety, and auditability.

If OpenRouter is unavailable, leave fallback mode visible. It is an intentional transparent demo layer, not a disguised live result.
